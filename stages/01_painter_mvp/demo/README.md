# GO_FLORA Stage 01 — оригинальная демонстрация

Статус: **READY_FOR_MANUAL_QA**, Godot **4.7.2**. В сцене нет стороннего искусства и заранее нарисованных размещений. Владелец выполняет реальные действия по [сценарию приёмки](../manual_qa.md); автоматические результаты приведены в [отчёте](../report.md).

## Запуск из репозитория

1. Из корня репозитория: `python tools/prepare_stage01.py`. Скрипт копирует addon и тесты внутрь демо; эти копии и `.godot/` игнорируются Git. Авторскую сцену он не перезаписывает.
2. Откройте этот `project.godot` в Godot 4.7.2. GO_FLORA уже включён в Project Settings → Plugins.
3. Откройте `demo.tscn`, выберите `VegetationLayer`, перейдите в 3D. В dock GO_FLORA выберите набор и режим. При изменении дерева сцены нажмите Refresh Layers / Sets.
4. Paint / Erase: удерживайте ЛКМ и двигайте мышь по коллайдеру; отпустите для одного Undo-действия. Single: один клик. Esc отменяет pending stroke. Navigate пропускает управление редактору. ПКМ/СКМ/Alt/Ctrl передают навигацию Godot и отменяют pending stroke.
5. Сохраняйте свою QA-сцену через Save As, например `qa_owner.tscn`, чтобы оставить исходную демонстрацию воспроизводимой. Не запускайте `--build-demo` после начала QA: этот отдельный служебный режим пересоздаёт исходную сцену.

## Объекты

- Зелёный конус высотой 1,5 м и оранжевый куб высотой 0,8 м — два различных статических Mesh, материалы и pivot-offset собственного изготовления.
- `set-a` / «A · near vegetation»: веса cone:box = 3:1, дальность 10 м. `set-b` / «B · far vegetation»: 1:3, дальность 80 м. Каждый набор можно рисовать независимо; оба содержат оба источника.
- `Ground`: серая плоскость 18×18 м с BoxShape-коллайдером, верх на Y=0.
- `RotatedScaledSurface`: синяя поверхность с поворотом (12°,15°,22°), масштабом (1,3;0,9;0,8), своим коллайдером. Default slope max=60° допускает её нормаль.
- `VisualOnlyNoCollision`: жёлтая поверхность в (-12;1;3), за пределами Ground, без коллайдера. Наведение не должно давать подходящий target.
- `VegetationLayer`: единичная трансформация, cell size 8 локальных единиц, независимые наборы с persistent logical records. Render cells и курсор не сохраняются как авторские узлы.

Для хорошо видимого первого рисования временно задайте дальность A=0 через **Edit Set in Inspector**, затем выполните отдельную проверку A=10 и B=80 после размещения. Расстояние считается Godot до центра batch-ячейки; MultiMesh скрывается целиком. Это не brush radius и не per-instance culling.

После сохранения QA-сцены можно запустить её F6. В runtime камера: клавиша **1** — (6;5;7), **2** — (28;18;30), обе смотрят на origin; WASD перемещают камеру. Рисуйте тестовые A/B около origin и по обе стороны границы ячеек: ближняя/дальняя позиции должны показать работу A=10 и B=80. Эти runtime-позиции дополняют обязательную проверку камеры в самом редакторе.

Опционально `res://tests/manual_inspect.gd` из Script Editor → File → Run сохраняет снимок записей и текущих batch-настроек в `.scratch/manual_snapshot_*.json`. Он только читает данные; запуск скрипта не является GUI-приёмкой. Подробнее — [manual QA](../manual_qa.md).

Addon можно отдельно установить копированием корневого [addons/go_flora](../../../addons/go_flora/README.md) в другой проект. Лицензия собственного кода/сцены/документации — [MIT](../../../LICENSE); условия сторонних компонентов не изменены.
