# Stage 01: доступная дальность набора и стабильная ширина дока

Дата: 2026-10-15. Addon: **0.1.2-dev**. Статус: **READY_FOR_MANUAL_QA**.

Владелец подтвердил первое интерактивное рисование в TEST_FLORA: «Работает». Это OWNER_REPORTED_PASS только для первого Paint; Undo/Redo, повторное открытие и визуальная дальность ещё не приняты. Он также сообщил о скачках ширины дока при нажатии мышью и не нашёл Draw Distance M. Это зарегистрированный OWNER_REPORTED_FAIL интерфейса версии 0.1.1-dev, без агентской GUI-проверки.

## Изменения

- Поле **Draw distance (m)** находится непосредственно под выбором набора. **0 = без ограничения**. Действие привязано к истории текущей сцены; Undo/Redo и изменения через Inspector синхронизируют поле. Меняется только выбранный ресурс набора, существующие batch-узлы сохраняются, records не переписываются.
- Начальная позиция GO_FLORA — группа Scene/Import (`DOCK_SLOT_LEFT_UR`, слева в стандартной раскладке). Inspector остаётся отдельно. Сохранённая Godot раскладка может восстановить прежнюю позицию: вкладку можно один раз перетащить в Scene/Import. Пользовательская раскладка на диске не редактируется.
- ScrollContainer изолирует обе оси минимального размера, резервирует вертикальную полосу прокрутки. Счётчик переносится на строки, подписи полей переносятся, превью используют HFlowContainer, режимы размещены в две колонки. Горизонтальная прокрутка доступна как резерв при очень узком доке. Длинные сообщения и счётчики не требуют расширения разделителя редактора.
- Схема данных, размещения и архитектура ADR 0001 не изменены. Только Stage 01; Stage 02, релиз и слияние не выполняются.

## Обновление TEST_FLORA

1. Сохранить сцену **Ctrl+S**, закрыть Godot.
2. Распаковать новый plugin-only ZIP в `C:/Dev/TEST_FLORA`, заменив только `addons/go_flora/`.
3. Открыть проект. При сохранённой прежней позиции перетащить вкладку GO_FLORA к Scene/Import.
4. Выбрать слой и набор A; поле Draw distance (m) видно сразу под набором. Для первого Paint оставить 0. Для проверки дальности поставить A=20, B=80 и перемещать камеру ближе/дальше; count не должен изменяться.
5. Проверить отсутствие скачков ширины при Paint/Erase/Single, затем Undo/Redo, сохранение и повторное открытие.

Архив содержит только addon и MIT notice; сцены TEST_FLORA в него не входят. Живой TEST_FLORA в этом обновлении не изменялся: несохранённое рисование владельца не затрагивалось.

Выбор dock-slot сверялся с [официальным EditorPlugin API](https://docs.godotengine.org/en/latest/classes/class_editorplugin.html), scroll modes — с [ScrollContainer API](https://docs.godotengine.org/en/latest/classes/class_scrollcontainer.html). Совместимость подтверждена выполненными native проверками на точной версии 4.7.2, а не только чтением latest-документации.
