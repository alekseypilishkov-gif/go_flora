# Ручная приёмка 0.2.1-dev

**INTERACTIVE_GUI_QA: NOT_RUN. READY_FOR_MANUAL_QA.** Автоматические API/GPU результаты не считаются мышиной проверкой. TEST_FLORA агент не изменял; установку ZIP выполняет владелец после сохранения сцен и закрытия Godot. Архив содержит только addons/go_flora; соседние manifest/SHA оставить для optional installer.

1. Установить ZIP в выбранный проект. Сохранённый layout Godot сохраняется; если восстановился прежний левый slot, один раз перетащить GO_FLORA к Inspector. В новом проекте default справа. Ctrl+Alt+G возвращает палитру. Проверить доступность FileSystem/Output/Inspector и стабильность ширины при длинных названиях/статусах.
2. Выбрать слой и набор с Green cone bush, Orange block shrub, grass, flower. Проверить читаемые имена, preview, тип/ID по hover, флажок и вес. Open Set in Inspector должен показать именно этот набор и именованные строки. Выбрать другой узел, другой set и другую сцену, повторить.
3. Нажать grass: Brush sources = Selected source only. Paint должен давать только grass; Single — одну grass. Повторить flower. Вернуть Mix by weights, убедиться, что веса/состав не менялись.
4. Выключить cone/cube: прежние размещения остаются. MIX добавляет только grass/flower. Изменить вес, Undo/Redo; флажки, веса, старые IDs/позиции сохраняются. Включить обратно: сохранённые положительные веса восстановлены без переназначения.
5. Все флажки off или все веса 0: MIX показывает диагностическое сообщение и не рисует. Выбранный off источник блокирует Selected. Включённый источник weight=0 рисуется в Selected. Erase прежних записей работает при off источниках; Undo возвращает их.
6. Проверить hover на основных полях кисти и Create Alpha Plant (включая Atlas X/Y/W/H, gutter, alpha). Help / Справка открывает русскую легенду. В Inspector есть помощь Enabled / Density / Distance.
7. Paint/Erase/Single мышью на обычном/наклонном collision; Esc, отпускание за viewport, RMB/MMB/Alt/Ctrl navigation; Undo/Redo. Draw Distance: 0 без ограничения, малое число скрывает cells всего текущего набора; другой набор/record transforms не меняются.
8. Добавить собственные GLB, PNG и WebP. Убедиться в alpha-scissor без прямоугольного фона; изменить импорт/переимпортировать и проверить сохранность размещений. Переименовать display_name и проверить обе палитры. Временно недоступный source диагностируется, записи сохраняются.
9. Сохранить сцену, закрыть и открыть Godot. Проверить disabled флажки/веса, размещения, Draw Distance и собственное положение dock. Отключить/включить plugin: один dock, одна палитра Inspector, без ошибок.

Результаты владельца и замечания фиксируются отдельно. PR #6 остаётся Draft; merge/release/Stage 03 здесь не разрешены.
