# Ручная приёмка 0.2.3-dev — только интерфейс Godot и Проводник

**INTERACTIVE_GUI_QA: NOT_RUN. READY_FOR_MANUAL_QA.** Автоматические native API и GPU пробы не заменяют физическую проверку мышью. Выполняет владелец в своей существующей сцене.

## Установка

1. Закройте Godot с проектом TEST_FLORA. Через Проводник скопируйте прежнюю папку `C:\Dev\TEST_FLORA\addons\go_flora` в backup вне проекта.
2. Вставьте в адресную строку Проводника путь `C:\Dev\GO_FLORA\stages\02_imported_alpha_vegetation\updates\03_erase_palette_remove\.scratch\packages`.
3. Выберите **GO_FLORA_stage02_0.2.3-dev_2e26e47a.zip**, нажмите **Извлечь всё…**. Во временной папке откройте `addons`, скопируйте `go_flora` в `C:\Dev\TEST_FLORA\addons`, подтвердите замену. Не создавайте лишнюю вложенность `addons\addons`.
4. Откройте TEST_FLORA. Дождитесь импорта. В Project → Project Settings → Plugins проверьте GO_FLORA **0.2.3-dev** и включённый плагин. Откройте прежнюю сцену и слой VegetationLayer3D; Ctrl+Alt+G открывает палитру.

## Непрерывный Erase

- [ ] Убедитесь, что прежние PNG grass/flower, WebP, Mesh/GLB и Mix/Selected видны и рисуют как раньше. Сделайте рабочую копию сцены через Save As.
- [ ] Нарисуйте плотную область в несколько тысяч растений и длинную полосу. Выберите Erase, удерживайте ЛКМ и проведите непрерывно через область. Проверьте медленное и быстрое движение, начало/конец полосы и последние нарисованные растения.
- [ ] Отпустите ЛКМ **внутри 3D viewport**. При оставшейся очереди дождитесь статуса завершения. Растения под полным путём должны исчезнуть, повторные клики для обхода лимита не нужны.
- [ ] Один Ctrl+Z восстанавливает весь мазок; один Ctrl+Shift+Z повторяет всё стирание. Другой набор не меняется.
- [ ] Плотную область очистите одиночным кликом, затем Undo. Удерживайте курсор неподвижно после нажатия: обработка должна завершаться без движения и дополнительных кликов.
- [ ] Проверьте Erase для выключенного источника, на наклонной поверхности и при transform слоя. Locked records не стираются.
- [ ] Начните длинный мазок и нажмите Esc, включая во время завершения очереди после MouseUp: всё сохраняется, лишнего Undo нет.
- [ ] Начните мазок и отпустите ЛКМ за пределами viewport: мазок отменяется. Проверьте переключение сцены/набора и потерю фокуса — незавершённая работа также отменяется.
- [ ] Навигация Godot (Alt, средняя/правая кнопка), hover preview и ограничения collision target работают как раньше. Между раздельными подходящими поверхностями через неподходящий участок не должно возникать стирающего мостика.

## Безопасное удаление источника

- [ ] В dock нажмите **−** рядом с именем растения, у которого есть размещения. Диалог показывает количество и объясняет сохранение растений. Нажмите **Убрать из палитры**.
- [ ] Строка исчезла, размещённые растения остаются видимыми. Mix не добавляет удалённый источник. Если он был выбран в Selected, показана явная просьба выбрать доступный источник, другое растение тайно не рисуется.
- [ ] Один Undo возвращает строку на прежнее место, с прежним весом/enabled; Redo убирает строку, сохраняя растения. Повторите из **Open Set in Inspector** кнопкой **−** в именованной палитре.
- [ ] Сохраните сцену с удалённой строкой, закройте Godot, откройте проект и прежнюю сцену заново. Все размещённые растения видны; потерянных Source diagnostics нет.
- [ ] Через Inspector → Add Existing Source верните тот же `.tres`. Он снова рисует, видимые растения сохраняются. Повторное добавление уже активного Source не создаёт второй строки или Undo. Undo/Redo успешного возврата меняет только членство в палитре.
- [ ] У источника без размещений **−** удаляет строку сразу. Undo восстанавливает точное место/вес/enabled.

## Явное удаление размещений

- [ ] Для источника с размещениями нажмите **−**, затем **Удалить и размещения…**. Открылось **отдельное** подтверждение с точным количеством. Cancel ничего не удаляет.
- [ ] Подтвердите удаление. Исчезают строка и только размещения этого источника в данном наборе/слое. Другой источник, другой набор и другая сцена не меняются.
- [ ] Один Undo восстанавливает строку и все размещения; один Redo повторяет удаление. Проверьте существование оригинальных `.tres`, PNG/WebP/GLB в FileSystem — они должны остаться.
- [ ] Смените набор/сцену при открытом диалоге: он закрывается без изменения данных. Quick Load / Load / Create Alpha Plant / Save Source / Help продолжают работать без конфликта exclusive windows.

Запишите PASS/FAIL по пунктам и конкретную сцену/набор/источник. Для FAIL укажите последовательность действий и приложите скриншот/Output. До этой приёмки стадия не объявляется физически проверенной или завершённой владельцем.
