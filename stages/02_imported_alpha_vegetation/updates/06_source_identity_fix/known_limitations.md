# Известные ограничения Stage B

- Контракт canonical external .tres относится только к новым Source из Creator 0.2.6-dev. Старые встроенные объекты могут независимо существовать рядом с внешними .tres с тем же source_id/display_name. Автомиграции, relink, дедупликации и переноса Scene Fallback approval нет.
- Проверка свободного пути выполняется непосредственно перед записью в главном потоке редактора. Это не межпроцессная атомарная блокировка: внешний конкурентный writer, crash/power loss и recovery не реализованы.
- После успешной записи и неудачной загрузки/валидации файл намеренно остаётся. Сообщение содержит путь; удалить или переименовать его может владелец после проверки. Creator не делает overwrite и не удаляет такие файлы.
- Внешние ассеты остаются внешними ссылками. Snapshot сверяет путь/класс внешней зависимости, а её внутреннее содержимое и reimport продолжают обслуживаться существующим Resolver. Встроенные Mesh/материалы/AlphaCard сравниваются по stored properties; float допускает погрешность текстовой сериализации Godot.
- Намеренные пользовательские Make Unique, Convert to Built-in, ручная правка resource_path/ID или прямое сохранение внешнего Source через Inspector находятся вне защиты нового Creator. Это не запрет обычного редактирования существующего внешнего Source.
- Смена активного layer/Set после записи оставляет валидный .tres без добавления в другой Set. Его можно добавить через Set Inspector. Исторические ограничения append/Undo/архива не менялись.
- На Windows существующий installer зависит от доступной длины пути: первая установка в глубоко вложенный stage-каталог завершилась FileNotFoundError на длинном пути временного backup. Повтор той же пробы в коротком disposable .scratch/qa018 прошёл. Installer в Stage B не менялся; для глубоко вложенных рабочих проектов это остаётся ограничением. Evidence: evidence/package/package-tests.log и evidence/package-green/installation-summary.json.
- Native Editor API и настоящий графический Save/thumbnail прошли на Windows/NVIDIA RTX 5060 Ti. Полная ручная навигация, клики, Save Dialog и приёмка в TEST_FLORA — **NOT_RUN**. Другие GPU, платформенные графические редакторы и crash recovery — **NOT_RUN**.
- Ранние автоматические пробы использовали общий игнорируемый portable cache Codex; финальные all-green/graphics-green выполнены с отдельными binary/editor_data. Ни одна проба не запускала TEST_FLORA.

Статус: **READY_FOR_MANUAL_QA**. Merge/release не выполняются.
