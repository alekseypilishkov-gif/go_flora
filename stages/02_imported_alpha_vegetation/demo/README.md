# Stage 02 — оригинальная демонстрация

**READY_FOR_MANUAL_QA. INTERACTIVE_GUI_QA: NOT_RUN.** Все модели/текстуры/сцены созданы для GO_FLORA и распространяются по [MIT](../../../LICENSE). Сторонние ассеты отсутствуют. [Манифест](fixtures/manifest.json) содержит SHA исходных fixtures; генератор — `tools/create_stage02_fixtures.py` (Python + Pillow, только для воспроизводства тестового арта).

Из корня репозитория:

```text
python tools/prepare_stage02.py --godot .scratch/godot-portable/godot.exe
```

Откройте этот `project.godot` в Godot 4.7.2 и `demo.tscn`. Подготовка копирует только актуальный addon в этот отдельный demo-проект. Для пересборки самой сцены используйте дополнительный `--build-demo`; это перезапишет демонстрационный `demo.tscn`, поэтому собственную приёмку сохраняйте как `qa_owner.tscn` (ignored).

Сцена содержит **137 сохранённых logical records**: 112 на обычном Ground, 24 на синей наклонной collision surface, 1 authored fallback. Набор A смешивает настоящий GLB, static PackedScene, crossed PNG-траву и single PNG-цветок; B — 4-card WebP-траву и выбранную область атласа. C — отдельная рассмотренная сцена с не-tool скриптом, сигналом, группой и настоящим коллайдером. В редакторе C отображается инертным mesh-превью, в runtime запускается её поведение. Жёлтая поверхность не имеет collision.

GLB содержит две mesh-части / три поверхности с разными материалами, UV/нормалями/тангентами и вложенными неравномерными transform. Это настоящий бинарный GLB, который Godot импортирует штатно. Прозрачные PNG/WebP/атлас лежат в `fixtures/`; файлы `stage01_saved.tscn`/`stage01_expected.json` — замороженная регрессионная сцена, сохранённая исходным Stage 01 до изменений addon.

Для собственной травы: выбрать VegetationLayer и набор → **Create Alpha Plant…** → Texture2D PNG/WebP → Single/Crossed/Radial → размеры/UV rectangle в пикселях → Save Source. Ресурс `.tres` добавится в текущую палитру. Для модели сначала импортируйте GLB в Godot, затем **Add Mesh / GLB / Scene…**. Параметры сохранённого источника доступны через dock-превью/Inspector; веса — Edit Set in Inspector.

A начинается с distance=0, B=80. После рисования измените A, переместите камеру, затем верните 0. Runtime F6: клавиши 1/2 дают ближний/дальний ракурс, WASD перемещает камеру. Это дополняет редакторскую приёмку, не заменяя её. Сцену C и её простой скрипт можно изучить до проверки fallback.

Далее выполните [manual QA](../manual_qa.md). Рабочий TEST_FLORA подготовка не читает и не меняет. В архив обновления входят только файлы addon; эта сцена и текстуры туда не включены.
