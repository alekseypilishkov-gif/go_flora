# ADR A — implemented Stage 01 contracts

[ADR 0001](ARCHITECTURE_ADR_0001.md) is accepted. This document identifies the implemented vertical slice; the ADR's wider provider/migration/LOD proposals remain future work.

| Contract | Implemented representation and behavior |
| --- | --- |
| Static source | `GFVegetationSource`: stable source ID, Mesh asset, effective per-surface material overrides on a shallow Mesh copy, source pivot transform, variant revision. No user material is globally mutated. Unsupported source kinds/resources return diagnostics. No PackedScene flattening or native provider. |
| Weighted set | `GFVegetationSet` + `GFPaletteEntry`: stable set/source IDs, source-ID-sorted weighted selection, enabled, density multiplier, draw distance in metres. Invalid/NaN/infinite/negative values rejected; 0 distance is unlimited. Presentation changes notify existing batches through `Resource.changed`. |
| Persistent layer | `VegetationLayer3D.layer_data`: scene-local `GFVegetationLayerData`, schema 1, set resources, stable layer ID, typed records and next stroke serial. `resource_local_to_scene` avoids shared placement state between scene instances. Duplicate scene copies retain IDs intentionally; IDs must not be reassigned to unrelated content. |
| Instance record | Schema 1, SHA-256 record ID, source/set/layer/stroke IDs, resolved source revision, local transform/normal, seed, candidate index, initial cell hint, flags, target path, `sha256-counter-v1` algorithm. Locked flag bit 0 is not erased; hidden bit 1 is not rendered. Records/serial are stored with scenes; they are not MultiMesh slots. |
| Determinism | SHA-256 of a structured array containing algorithm, seed, stroke ID, candidate index and purpose. Independent counters for source/radius/angle/yaw/scale prevent rejection rerolls. Same layer ID/serial/seed/parameters/path yields the same result. Repeated new strokes advance serial; undo restores serial, and new work invalidates old redo through Godot history. |
| Stroke | Pending additions and ordered removals are separate from authoritative records. Spacing resamples world path length; initial disk area and subsequent strip area accumulate sample credit. Candidate/stamp work is bounded. This is a density approximation for overlapping strokes, not Poisson-disc sampling or biome generation. |
| Commit/history | One scene-bound `EditorUndoRedoManager` action per finished Paint/Erase/Single; do/undo apply exact record deltas and serial values. Cancel discards cache preview only. Native history isolation is tested separately from real mouse acceptance. |
| Transform | Placement world transform is multiplied by `layer.global_transform.affine_inverse()`. Normal is transformed with the layer basis transpose. Moving/rotating/nonuniformly scaling the layer keeps local records unchanged. Source pivot is applied at cache construction. |
| Rendering | Resolver/cache uses only static source Mesh/materials. Group key includes layer, set, floored local X/Z cell, source, current source variant revision, Mesh identity and effective surface-material identities. One local MultiMesh per group, conservative transformed AABB. Distance updates current set's existing batch nodes; no records change and no full rebuild is needed for this edit. |
| Cache lifecycle | Internal, unowned cache root and cursor do not pack into authored scenes. Records rebuild caches on reopen, enabled runtime and resource edits. Cell size changes rebuild grouping from current local transforms; stored `cell_key` is an initial hint, not a persisted render address. Current MVP rebuilds all batches for record/topology edits, coalesced per frame. Incremental dirty-cell optimization is deferred. |
| Failure behavior | Newer/invalid schema is read-only and suppresses cache creation without clearing data. Missing/unsupported sources produce diagnostics and skip unavailable render parts, retaining all records. No migrations or automatic source substitution. |

Layer/render scripts do not reference EditorPlugin or other editor-only classes; editor controls live under `editor/`. Mesh resource changes rebuild caches without changing stable record transforms. Existing source asset/revision edits deliberately resolve to that source's current Mesh; preserving historical provider variants is deferred. Do not change stable IDs after placement or manually edit internal records.

Native core/physics/resource/history test results are in the [Stage 01 report](../stages/01_painter_mvp/report.md). Interactive acceptance remains NOT_RUN until the owner completes the [manual script](../stages/01_painter_mvp/manual_qa.md).
