# Stage 02.1: совместимость палитры и интерфейса

[Issue #7](https://github.com/alekseypilishkov-gif/go_flora/issues/7), версия 0.2.1-dev. Дополнение к [Stage 02 contracts](STAGE_02_SOURCE_CONTRACTS.md), без смены схемы 1 или миграции сцен.

- `GFPaletteEntry.enabled=true` — единственное новое сериализуемое поле. Старые сцены получают true по умолчанию. Source/weight, значения enum, stable IDs, records, transforms и RNG сохраняются. Source/set display_name теперь уведомляет наблюдателей об изменении.
- MIX фильтрует enabled && finite weight > 0, сортировка по source_id и формула SHA256-counter-v1 прежние. Все включены — прежняя последовательность выбора; 1000 сравнений с исходной формулой и frozen Stage 01 scene проверяются отдельно.
- `selected_source_id` — необязательный последний аргумент stroke.begin/make_record. По умолчанию пустой, прежние callers работают без изменений. В режиме Selected требуется включённый валидный источник; вес не используется, включая 0. Неверная/исчезнувшая ссылка не вызывает молчаливого выбора другого растения. Erase не требует доступного источника.
- Выбор растения и Mix/Selected — временное состояние EditorPlugin. Ничего не записывается в набор/records/project.godot. При переключении набора выбранный ID запоминается в текущем сеансе; смена сцены/перезапуск плагина сбрасывает его. Single — отдельный инструмент: одна запись выбранного/смешанного источника.
- enabled/weight/ссылки редактируются через EditorUndoRedoManager с контекстом слоя/сцены; внешний набор без слоя использует историю ресурса. Названия/тип/ID/preview и значения синхронизируются между dock и Inspector через changed. Наблюдатели отключаются при смене набора/плагина. Выключение источника не фильтрует renderer: старые размещения продолжают отображаться. Включение набора Enabled сохраняет прежнюю семантику видимости всего набора.
- EditorInspectorPlugin заменяет только `entries` на EditorProperty с именованными строками, нативными EditorResourcePicker и добавлением существующей ссылки. Остальные поля остаются нативными. Resource.resource_name не меняется; destructive delete отсутствует. Замена источника сохраняет записи, но прежний source_id должен оставаться разрешимым для их отображения.
- Новый default `DOCK_SLOT_RIGHT_UL`; bounded ScrollContainer 260×120. Layout не сбрасывается и не пишется плагином. Сохранённый старый левый slot переносится владельцем однократно. Ctrl+Alt+G зарегистрирован через официальный Shortcut аргумент add_control_to_dock.
- `EditorInterface.inspect_object(resource, property, true)` меняет inspected object. В Godot 4.7.2 одного этого вызова недостаточно для активации скрытой вкладки: это выявил runtime probe. Плагин находит публичный тип `EditorDock` среди предков возвращённого официальным get_inspector() контрола и вызывает документированный `make_visible()`. Нет имён узлов, индексов детей, приватных методов, поиска по всему дереву или записи layout. Отсутствие такого предка не вызывает ошибку; именованная dock-палитра остаётся доступной. Тест начинает именно с GO_FLORA активной вкладкой и проверяет Inspector.is_visible_in_tree().

Основание API: [Inspector plugins](https://docs.godotengine.org/en/stable/tutorials/plugins/editor/inspector_plugins.html), [EditorInterface](https://docs.godotengine.org/en/4.7/classes/class_editorinterface.html), [EditorDock.make_visible](https://docs.godotengine.org/en/4.7/classes/class_editordock.html#class-editordock-method-make-visible). Документация/исходник являются source evidence; фактический результат подтверждается отдельными native Editor API probes на `4.7.2.stable.official.ed1daf0bf`. Эти проверки и GPU captures не заменяют реальную мышь/drag/navigation/save acceptance владельцем.
